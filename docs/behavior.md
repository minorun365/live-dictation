# 動作の詳細

## メニューバー

ウィンドウを閉じてもアプリはメニューバーに残り、会議の検知を続けます。アイコンから状態の確認、録音の開始と停止、ウィンドウの再表示ができます。待機中は眠っている絵、録音中はメモを取る絵になります。「対面会議を開始」を選ぶと、ウィンドウを開かずに対面モードで録音を始められます（このときウィンドウで選んでいるモードは変わらないので、次のWeb会議は日本語モードのまま自動で始まります）。終了は⌘Qです。

## 英語の会議

会議の検知で始まる録音は、ウィンドウで選んでいるモード（初期値は日本語）になります。英語の会議は、メニューバーから次のどちらかで英語モードにできます。

- 「英語会議を開始」は、その録音だけを英語モードで始めます
- 録音中の「英語モードに切り替える」は、日本語で始まってしまった録音を閉じ、続けて英語モードで録音し直します。音声認識の言語は録音の開始時に決まるため、切り替え前の分は別の短いセッションとして残り、切り替えの瞬間の音は残らないことがあります。会議アプリがマイクを離すと止まる動きは、切り替え後の録音にも引き継ぎます

日本語訳はウィンドウが開いている間だけ動くため、英語モードで録音が始まるとき、ウィンドウが閉じていれば自動で開きます。

## 話者の分け方

日本語モードは行頭に「自分：」「相手：」を付けます。マイクとMacの再生音をそれぞれ別の音声認識にかけているだけで、声を聞き分けてはいません。そのためスピーカーで相手の声を鳴らすとマイクにも入り、同じ発言が自分の側にも記録されます。ヘッドホンの利用をおすすめします。

## 録音中の画面とフタ

録音している間は、画面が省電力で消えないようにします。macOSは画面と音声をひとつの仕組みで取り込むため、画面が消えると録音ごと止まり、マイクの音も届かなくなるからです。録音を終えると元の設定に戻ります。それでも何らかの理由で取り込みが止まった場合は、自動でつなぎ直します。

録音中にヘッドホンをつなぐ・外すなどして音の出力先が変わっても、録音は続きます。切り替わった瞬間の音は残らないことがあります。つなぎ直したことは `events.jsonl` の `meeting_audio_engine_restarted` に残ります。

録音中にフタを閉じても、録音は終わりません。MacBookはフタを閉じるとマイクがハードウェアで切れるため、閉じている間の音は残りませんが、フタを開けて画面のロックを解除した時点で同じ録音へつなぎ直します。会議室へ移動するあいだ閉じておき、着いてから開く使い方を想定しています。

## 自動で録音が始まる条件

会議アプリがマイクを使い始めると録音を開始し、そのアプリがマイクを離してから1分で停止します。

- 対象はZoom、Microsoft Teams、Webex、Slackのハドル、Discord
- ブラウザーのGoogle Meetなどは、マイクと再生の両方を使っているときだけ会議とみなします
- 音声入力アプリやmacOSの音声認識では始まりません
- 「手動で録音開始」で自分から始めた録音は、会議アプリの状態では停止しません。止め忘れに備えて3時間で自動停止します

## 対面会議のリマインド

対面会議はどのアプリもマイクを使わないため、会議アプリの検知では始まりません。代わりに、開始5分前に「対面で録音開始」ボタン付きの通知を出します。通知かボタンを押すと、対面モードで録音を始めます。

- メニューの「対面会議を自動で録音」をオンにすると（初期値はオフ）、次の2つが加わります
  - 開始5分前の通知の代わりに、何も録音していなければ対面モードの録音を自動で始め、「録音を止める」ボタン付きの通知を出します。一度始めた会議は、途中で手で止めても始め直しません
  - 通知のボタンか自動で始めた録音を、終了予定の10分後に止めます。その2分前に「録音を続ける」ボタン付きの予告を出し、押すとその会議の録音は止めません
- 会議の一覧は `~/Library/Application Support/LiveTranslator/InPersonMeetings.json` から読みます。アプリはカレンダーに接続しないので、このファイルは別のツールで書き出してください（下の形式）。ファイルが無ければ通知は出ません
- 5分前にMacが眠っていた場合は、会議が終わる前に目覚めた時点で通知します
- 何かを録音している間（直前のWeb会議など）は通知を出さず、録音が終わってから出します。画面共有中に通知が映るのを避けるためです
- 一覧の更新が30分以上止まると、メニューに「対面会議の予定の取得が止まっています」と表示します

```json
{
  "fetchedAt": "2026-09-28T16:00:00+09:00",
  "meetings": [
    {"id": "abc123", "title": "定例", "start": "2026-09-28T16:30:00+09:00",
     "end": "2026-09-28T17:00:00+09:00", "location": "会議室A"}
  ]
}
```

## 文字起こしの遅れ

録音中は、macOSの省電力でアプリの動きが抑えられないようにしています。音声と認識結果の時間差は `events.jsonl` の `recognition_lag` に約1分ごとに残り、60秒以上遅れると、溜まった分の確定を認識エンジンへ促します。このとき、文の途中で確定に切れることがあります。

## 保存されるもの

`~/Library/Application Support/LiveTranslator/Sessions/` の下に、セッションごとのフォルダを作ります。

- 録音音声（日本語モードは自分と相手を別ファイルに分けます）
- Markdownの文字起こしと要約
- 録音中の画面を1秒ごとに撮った `screenshots/`（会議のウィンドウが見つかればそのウィンドウだけ、見つからない間は全ディスプレイを並べた1枚）

`screenshots/timeline.md` には画面が変化した時点をまとめてあり、Claude Codeなどからそのまま読み込めます。外部サーバーへ送信するコードは含みません。録音対象者や主催者の許可を得たうえで使用してください。
